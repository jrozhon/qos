[Slidev](https://sli.dev) decks for the QoS/QoE course, one file per lecture. They share one Slidev project:
the VŠB-TUO layouts, components, fonts, logos and `style.css` live here once, and every deck is a single

Decks are numbered like the lessons; add `04-…md`, … alongside.

## Run a deck

```bash
cd slides
npm install                                    # once
npm run dev -- 01-information-theory.md        # opens http://localhost:3030
```

Press `d` for dark mode, `o` for the slide overview, `p` for presenter mode (speaker notes are in the `<!-- -->`
blocks at the end of each slide).

## Export

```bash
npm run build  -- 01-information-theory.md     # static site in dist/
npm run export -- 01-information-theory.md     # PDF; needs: npx playwright install chromium
npm run export-notes -- 01-information-theory.md
```

`export` writes `<exportFilename>.pdf` from the deck's frontmatter. One page per slide with all click content
revealed; pass `--with-clicks` for one page per click.

## Writing a new deck

Copy the frontmatter of `01-information-theory.md` (theme, fonts, `mdc`, `exportFilename`) and follow the same
rhythm: cover → outline → thesis `statement` → `section` divider per part → content → summary → exercise preview →
references → `end`. Conventions that keep the decks consistent:

- **Layouts** available in frontmatter: `cover`, `default`, `center`, `section`, `statement`, `end`.
- **Checkpoints** — a `.checkpoint-question`, the muted "Predict first · discuss with a neighbour · then reveal"
  line, and a `.checkpoint-answer` with `v-click`. Give students 30 s to think and 30 s to discuss before revealing.
- **Speaker notes** on every slide, naming the exercise step or README question the slide serves.
- **Figures** are editable SVGs in `public/figures/<deck>/`, generated by `scripts/generate-figures.py`
  (standard library only; each deck has its own section in the script). They embed Carlito, carry a title and a
  description, and render at native size — 880 px wide for a full-width figure — via `class="lecture-diagram"`.
  Regenerate after editing:

  ```bash
  python3 scripts/generate-figures.py
  ```

- **Units in prose** must be escaped, `\[Hz\]`, because MDC syntax treats `[...]` as a span. Inside `$…$` KaTeX
  they are fine as they are.
- **Math** — KaTeX, `$…$` inline and `$$…$$` blocks. The closing `$` may not be preceded by a space.
- **Code fences** — Shiki has no grammar for RouterOS or similar; an unknown language is a hard build failure.
  Use `bash` for shell-like config.
- **First paragraph after a title** is body text; `style.css` overrides the theme's dimmed "subtitle" treatment.

## Visual style

The decks follow the VŠB-TUO 2023 visual identity manual. The rules, the palette, and the reasoning behind the
places where the manual and screen accessibility disagree are in [VSB-STYLE.md](VSB-STYLE.md) — read it before
changing colours, fonts, or the logo.

Short version: university green `#00A499` is primary, FEI cyan `#05C3DE` is the accent and never used for text,
type is Carlito (the manual's Calibri substitute, metric-compatible and open source), and everything is
hard-edged — no rounded corners or shadows.

Fonts and logos are self-hosted in `public/`, so the built site and PDF export don't depend on what's installed on
the presenting machine.

## Pinning the Slidev version

`package.json` uses `latest` for `@slidev/cli`; `package-lock.json` pins what was last installed. Delete the lock
file and reinstall to move to a newer Slidev.
